ПОРТФОЛИО ФОТОГРАФА

1. Откройте index.html в браузере, чтобы посмотреть сайт.
2. Номер WhatsApp сейчас указан как +7 777 777 77 77.
3. Для изменения номера замените 77777777777 в ссылках wa.me и отображаемый номер в index.html.
4. Чтобы добавить фото для всех посетителей, положите изображения в папку images и добавьте карточки по примеру из images/README.txt.
5. Для публикации загрузите index.html и папку images на любой статический хостинг.

Важно: кнопка «Добавить фотографии» на сайте показывает выбранные фото только в текущем браузере. Для общего онлайн-загрузчика нужен сервер или CMS с хранилищем и админ-доступом.
